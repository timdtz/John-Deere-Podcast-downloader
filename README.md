# John Deere Entdecker-Podcast downloader
Skript um Episoden des John Deere Entdecker-Podcasts als mp3-Datei runterzuladen.


Nach dem Feed-Laden werden alle Episoden nummeriert aufgelistet, bereits vorhandene sind markiert
Du kannst flexibel auswählen: new für nur neue, all für alle, oder beliebige Nummern/Bereiche wie 1 3 5 oder 1-5
